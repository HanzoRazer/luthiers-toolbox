## Standing NO-CALC

- Spreadsheets are **starting points**, not cut lists — measure *your* wood  
- 4-DOF model: fit-sensitive, not reliably predictive from CAD alone (Gore §2.4.1.1)  
- Brace sizing sheet is **experimental** (Holmberg, not full book formulas)  
- No mobility “exceptional” badges until Toolbox unit profile locked (**G-R01 / G-M09**)  
- Nylon \(E\) defaults are acknowledged inaccurate — prefer measure-rig  
- Do not ship species average thickness tables as production defaults
