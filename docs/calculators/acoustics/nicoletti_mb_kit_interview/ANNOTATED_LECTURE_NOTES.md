## 1. Purpose of measurement

### 1.1 Consistency and diagnosis, not a requirement for “a” great guitar  
**Timestamps:** ~1:26–2:44  

Analytical build/tune/optimize is helpful. Most of the time you don’t *need* it to build a great instrument; you need help to **always** build great ones — find problem sources and solve them. Unlock ~100% potential; small issues often block max beauty/tone.

## 3. Finished guitar vs build-stage corrections

### 3.1 Finished: tune only — resonances between notes  
**Timestamps:** ~6:23–7:21  

Finished: don’t aggressively change thickness/bridge. Tuning: resonances **between** notes; coincidence with fretboard note → fight — lose sustain, bad intonation, unpleasant note (fundamentals + harmonics).

## 5. Chladni as mode-shape map for targeted tuning

### 5.1 Why shape matters  
**Timestamps:** ~11:34–12:55  

Monopole always bridge-centered (easy). Dipoles/tripoles (cross/long) radiate mid-range; bracing moves pole geometry. Mode–note fights also happen on these higher modes.

| Field | Value |
|-------|-------|

### 5.2 Nodal lines; add mass at a pole  
**Timestamps:** ~13:04–14:18  

Speaker + dust → nodal lines (no vibration; dust gathers). To shift e.g. long tripole down: add a little mass on **one** of the poles (often enough). Map other modes so intervention doesn’t spoil them. Book visuals.

### 6.4 Monopole mobility = dynamic character / responsiveness  
**Timestamps:** ~17:04–18:09  

FRF → spectral balance (lows/mids/highs). **Monopole mobility** → dynamic character: high = very responsive; low = low responsiveness. High mass → less punchy, more lows; low mass → responsive, highs, punchy.

**Point ID:** N34

**Timestamps:** ~18:09–18:48  

Very light/high-mobility top + hard strumming → saturates / strange sound; better for fingerpicking / classical even balance → seek lower mass. Complete parameter picture also supports **reproducing** a guitar.
