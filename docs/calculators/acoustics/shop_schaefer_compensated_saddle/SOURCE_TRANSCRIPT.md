0:00 — Going into the weeds with compensation; worth it.

0:18 — Welcome back to DIY Guitar Making at Eric Schaefer Guitars. Today: converting a straight saddle into a fully compensated saddle. Guitar #119, commission for Doug. Originally built with a simple straight saddle; Doug has a very good ear — should have been fully compensated from the beginning.

1:01 — Sometimes straight, sometimes fully compensated — depends how fussy the customer is / how good their ear is. Straight saddle is fine for a large number, maybe the majority of musicians; most don’t notice the slight intonation difference. That’s why the straight saddle exists.

1:37 — Difference: not the steel-string *slanted saddle slot* vs classical straight-across slot. Steel needs more compensation because fretting steel sharpens more (especially thick→thin gauges). Nylon almost requires no compensation — very subtle. That slot geometry is a different effect (modulus of elasticity nylon vs steel).

3:35 — What we mean: not what the *slot* does, but what the *saddle itself* looks like.

3:45 — Straight saddle: radiused bone, crowned so string breaks dead center of saddle thickness → an *average* — a straight line between where strings want to intonate perfectly; close enough.

4:28 — Fully compensated: little ramps cut in; big long ramp on back edge. Most pronounced: **B string pushed all the way to the back**. B is first plain steel (descending from wound strings). Sharpening from fretting comes from **core** elasticity, not overall wound diameter. If windings stripped, diameters decrease E→A→D→G then **B core jumps up thick** — B break pushed back near bass E start. Plain treble E more like G in core diameter → similar flattening.

6:33 — Oversized blank sketch: mark E A D G B e. Bass E near back (stay off knife-edge). A a bit toward back of middle. D just forward of middle. G toward front (not knife). B all the way back like bass E. Treble e all the way front like G. Can carve individual ramps to points; nicer: straight line through E–A–D–G break points, steep ramp back for B, opposite ramp forward for e.

8:55 — Boutique guitar #119; ignore extended aesthetic saddle wing — pretend saddle starts at normal end. 1/8" wide saddle here. Can do on 3/32"; 1/8" best chance to hit points. Under 3/32" (e.g. 1/16") not enough room. Can widen slot (StewMac saddle routing jig recommended).

11:20 — Mark start of usable saddle; mark center G–B and B–e for ramp locations; long angled line across wound side.

12:01 — Modifying existing crowned saddle: if carving new compensated from scratch, **do not crown first**. Crowning + extreme B ramp drops break height (string sits lower after ramp). If action already high (esp. treble), modifying existing may land OK; if action already right, make a new saddle. Here treble a bit high → reuse existing.

15:36 — Pull saddle (string nippers to ease). Jeweler’s / StewMac nut-slotting vise with slanted jaws; can nest vice-in-vice — don’t buy two vices for this; clamp small vise to table.

17:03 — Draw layout; crosscut needle file. Start B: tilt file onto edge (knife-like) to define edges; modest angle — not knife point. Cut long front edge then long back edge; define inside corners with file tilted.

19:37 — Check intonation before cleaning file marks. Harsh truths before strobe work:

20:27 — Human ear limit ~**2–5 cents** for average musician (100 cents = 1 semitone). Don’t chase under ~2 cents; designing for humans.

22:02 — Any fretted instrument is an intonation compromise. Check harmonic vs fretted 12th (or open vs 12th). Not every mid-board note. Even perfect 12th ≠ perfect 7/5/4/3… Fretting stretches/sharpens; press-down amount varies by fret; string must rise toward saddle or elliptical vibration buzzes frets behind.

24:43 — True Temperament frets (squiggly CNC frets, Sweden company) = state-of-art if *only* optimizing intonation — shows how impossible “perfect everywhere” is on straight frets. Intonate at 12th; don’t drive nuts on mid-frets unless local problem (flat fret). Some advanced mid-fret systems exist — out of scope.

27:07 — Note envelope: time vs amplitude — starting transient peak then decay. Strobe may show transient at one pitch, decay sharp/flat. Prefer tune to **starting transient**, not chase both.

29:46 — Clip-on (e.g. Snark) vs strobe: clip-on fine for players tuning up; strobe for setting intonation (granular enough to drive you nuts). Demo: clip-on “perfect” while strobe still shows motion when knocked out.

32:36 — Walk strings with multiple plucks; finger pressure/bending affects reading; thick strings harder.

34:06 — Doug finds all steel-strings a bit out of tune; classical “perfect.” Steel has more high harmonic / overtone content; imperfect harmonicity + sensitive ear → psychoacoustic “out of tune” even when fundamental OK. Classical lower brashness less fraught.
