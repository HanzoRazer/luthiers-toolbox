# Schaefer — extracted process workflow (compensated saddle)

**Source pack:** this folder · **Lane:** shop / building  
**Builder:** Eric Schaefer · **Job:** straight → fully compensated bone saddle  
**Point IDs:** see [`ANNOTATED_WORKFLOW_NOTES.md`](./ANNOTATED_WORKFLOW_NOTES.md)  
**Rule:** Shop dialect. Widths / ear limits are *his* framing — not Toolbox defaults.

---

## Spine

```text
0  Decide: straight vs fully compensated (customer ear)
1  Confirm slot width (≥3/32"; prefer 1/8") — widen if needed
2  Mark usable saddle start + G–B / B–e ramp centers
3  Choose blank path: new uncrowned vs reuse crowned (action room?)
4  Remove strings / ease saddle
5  Fixture in jeweler’s vise
6  Layout break points (E A D G B e) / polyline + ramps
7  Needle-file ramps (edge-first; modest angles)
8  Restring; strobe 12th intonation (transient; multi-pluck)
9  Iterate carve if needed → then cosmetic cleanup
10 Client education: cents / fretted compromise / steel harmonics
```

---

## Stage 0 — Product / customer gate

| Step | Action |
|------|--------|
| 0.1 | Ask: does client notice / complain about steel intonation? |
| 0.2 | Straight OK for many; fully compensated for fussy / good ear |
| 0.3 | Document choice (SC01, SC36) |

**Gate:** Compensation depth agreed before carving.

---

## Stage 1 — Slot readiness

| Step | Action |
|------|--------|
| 1.1 | Measure saddle / slot width |
| 1.2 | Prefer **1/8"**; accept **3/32"**; reject **1/16"** without widen |
| 1.3 | Widen with StewMac-style saddle routing jig if needed (SC11–SC12) |

**Gate:** Enough width to hit aft/forward breaks without knife edge.

---

## Stage 2 — Marks before teardown

| Step | Action |
|------|--------|
| 2.1 | Define usable saddle start (ignore aesthetic extensions — SC13) |
| 2.2 | Mark center between G–B and B–e (SC14) |

**Gate:** Ramp loci marked on instrument or transferred to blank.

---

## Stage 3 — Blank decision (crown trap)

| Step | Action |
|------|--------|
| 3.1 | New compensated: start **uncrowned** (SC15) |
| 3.2 | Existing crowned: check action room — aft B ramp drops height (SC16–SC17) |
| 3.3 | If action already correct → new saddle |

**Gate:** Path chosen (reuse vs new).

---

## Stage 4–5 — Remove & fixture

| Step | Action |
|------|--------|
| 4.1 | Slacken / remove strings; ease saddle (nippers if tight) |
| 5.1 | Clamp in jeweler’s / nut-slotting vise (beveled jaws) |
| 5.2 | Optional nest in bench vise — not required |

**Gate:** Blank stable, top face accessible.

---

## Stage 6 — Layout

| Step | Action |
|------|--------|
| 6.1 | Mark six string positions |
| 6.2 | Place breaks: E aft, A aft-mid, D fwd-mid, G front, B aft, e front (SC09) |
| 6.3 | Draw line through E–A–D–G; B aft ramp; e forward ramp (SC10) |
| 6.4 | Stay off knife edges (SC20) |

**Gate:** Layout readable before filing.

---

## Stage 7 — Carve

| Step | Action |
|------|--------|
| 7.1 | Crosscut needle file |
| 7.2 | Define corners with file tilted on edge (SC19) |
| 7.3 | Cut B ramp, then long front / back edges |
| 7.4 | Modest angles only |

**Gate:** Ramps match layout; no razor breaks.

---

## Stage 8 — Strobe verify

| Step | Action |
|------|--------|
| 8.1 | Restring; use **strobe** (not clip-on alone) — SC29–SC31 |
| 8.2 | Compare harmonic (or open) vs fretted **12th** (SC24) |
| 8.3 | Tune judgment to **starting transient** (SC28) |
| 8.4 | Multi-pluck; watch pressure/bend (SC32) |
| 8.5 | Accept ~2–5¢ class; stop chasing sub-2¢ (SC22) |

**Gate:** Strings in “close enough” band at 12th; no knife-edge geometry.

---

## Stage 9 — Finish

| Step | Action |
|------|--------|
| 9.1 | Only after verify: clean file marks / polish |
| 9.2 | Recheck if material removed from break |

**Gate:** Cosmetic done without spoiling intonation.

---

## Stage 10 — Client education (anti-chase)

| Step | Action |
|------|--------|
| 10.1 | Fretted = compromise; mid-board won’t all match 12th (SC23–SC25) |
| 10.2 | Ear limit ~2–5¢ (SC22) |
| 10.3 | Steel high harmonics can *feel* out even when fundamental OK (SC33) |
| 10.4 | True Temperament exists but is not the default path (SC26) |

**Gate:** Client expectations set; avoid endless retrofit loops.
