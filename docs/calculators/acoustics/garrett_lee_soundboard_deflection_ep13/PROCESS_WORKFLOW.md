# Garrett Lee Ep. 13 — extracted process workflow

**Lane:** Physics (deflection SOP) + shop thinning  
**Builder context:** Classical solid top; 28-ft lower-bout radius; conventional fan bracing  
**Critical gap:** Numeric deflection **targets** were on-screen / spoken as “these numbers” but **not in ASR** — recover from video description before using as lab defaults (`G-GL01`).

---

## Spine

```text
0  Prepare plate (rosette in; underside free to thin)
1  Build / lock deflection format
2  Baseline scorecard (δ WG/CG, weight, thickness, tap)
3  Uniform thin (drum sand / plane) → re-measure
4  Preferential taper if with-grain still stiff
5  Stop in target ±10% band
6  Record final map + δ for correlation to finished sound
7  Later (other episodes): brace + dome → carve to resonances
```

---

## Stage 0 — Plate prep

| Step | Action |
|------|--------|
| 0.1 | Join/book-match top; inlay/level rosette |
| 0.2 | Keep underside available for material removal |
| 0.3 | Note density / cosmetics (demo: 0.40 g/cm³ spruce) |
| 0.4 | Cut outline with +4 mm overhang vs final edge |

---

## Stage 1 — Deflection format (lock once)

| Step | Action |
|------|--------|
| 1.1 | Dial indicator mid-span under plate |
| 1.2 | **With-grain supports:** slat at widest upper bout; other slat 10 mm inside final tail edge |
| 1.3 | **Cross-grain supports:** 10 mm inside widest upper & lower bouts |
| 1.4 | Weights — WG: preload 180 g, load 2 lb; CG: preload 30 g, load 180 g |
| 1.5 | Same plate size / outline family every time (smaller plate → less δ) |
| 1.6 | If adopting someone else’s numbers: recreate their format, hit their targets, then transpose to yours |

**Gate:** Format written down; reproducible registration (pins OK).

---

## Stage 2 — Measure (both axes)

| Step | Action |
|------|--------|
| 2.1 | Orient for with-grain; place plate on slats |
| 2.2 | Preload beside probe → seat plate |
| 2.3 | Zero dial |
| 2.4 | Apply load smoothly parallel to slats → read δ |
| 2.5 | Reorient slats for cross-grain; repeat with CG weights |
| 2.6 | Log: δ_WG, δ_CG, mass, thickness (or map), tap pitch/feel |

**Demo start (too stiff):** δ_WG ≈ 0.106", δ_CG ≈ 0.116".

**Gate:** Scorecard complete before removing wood.

---

## Stage 3 — Uniform thinning loop

| Step | Action |
|------|--------|
| 3.1 | Remove material from **underside** only |
| 3.2 | Prefer light drum-sand passes (or plane/scraper) keeping thickness even |
| 3.3 | Expect large flex change from small Δt (e.g. 0.1 mm passes) |
| 3.4 | Re-measure both axes + weight + tap after each session |
| 3.5 | Sneak up — do not overshoot targets |

**Physics reminder:** Δk roughly tracks t³ (and cross-grain often worse); k falls faster than mass → tap pitch drops.

**Gate:** Cross-grain near band; with-grain may still be stiff.

---

## Stage 4 — Preferential taper (if needed)

| Step | Action |
|------|--------|
| 4.1 | If with-grain still stiff but cross-grain OK/soft: sand lower bout / tail more than wings |
| 4.2 | Optional: thin around waist below future second transverse bar |
| 4.3 | Tool example: palm sander, 220 grit |
| 4.4 | Preserve **central peninsula** under future bridge (demo map ~2.3 mm center → ~1.8 mm rim) |
| 4.5 | Accept cross-grain past target if needed to free with-grain (bridge + optional cross bar later compensate) |

**Gate:** With-grain in ±10% of target; cross-grain tolerable.

---

## Stage 5 — Stop criteria

Stop when **all** agree:

1. Deflection in band (targets: **G-GL01**)  
2. Hand flex experience  
3. Tap pitch/character  

Then measure full thickness topography for records.

---

## Stage 6 — Record & correlate

| Step | Action |
|------|--------|
| 6.1 | Save final δ_WG / δ_CG, weight, t-map |
| 6.2 | After guitar finished, correlate to voice |
| 6.3 | Next top: use δ targets first; thickness only as ballpark |
