## Physics remnant

```text
Lock deflection format (spans, weights, plate size)
  → Measure WG + CG (preload/zero/load)
  → Thin uniformly toward targets
  → Preferential taper if WG lags
  → Stop in ±10% band (feel + tap + δ)
  → Record final δ, t-map, weight for next guitar
```
