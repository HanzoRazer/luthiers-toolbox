## 0. What kind of knowledge this is

A **visual build chronicle** with light narration. Value is in:

1. **Sequence** (what is done before what)  
2. **Named Somogyi fixtures/methods** (stiffness sanding, double sides, jigs)  
3. **Construction choices** that intersect Gore packs (solid linings, lattice, voicing stage, brace-into-lining)

Acoustic targets (Hz, mobility, wolves) are **almost absent** — logged as gaps.

### 2.2 Order of operations  
**Timestamps:** ~2:07–3:54  

1. **Finger braces** first  
2. **X brace** — notch, join, radius, glue  
3. **Laminated bridge plate** — two layers rosewood, fitted to X  
4. **Soundhole reinforcing donut** — fitted to X and transverse  
5. Glue **bridge plate + donut + transverse together** in one go  
6. **Lattice** — Irvin notch jig → glue lattice → radius bottom → cut upper arms to fit over bridge plate → glue  
7. Extra piece on bridge plate + **center-seam reinforcement**  
8. **Cut soundhole last** (after bracing)

| Field | Value |
|-------|-------|
| Classification | **IS**/AP sequence |
| Notable | Soundhole cut **after** structure — protects plate during bracing |
| Toolbox destination | Guided build sequence; Art Studio bracing stages |
| Gap | Lattice vs X hybrid geometry dimensions |

## 7. Neck, fretboard, bolt-on system

### 7.1 Mortise / fretboard / headstock  
**Timestamps:** ~15:53–19:37  

Sand neck contact area. Mortise: Irvin jig, **router held sideways**. Fretboard: Irvin slotting jig; bind (keep slots clean); 12th-fret block from fretboard offcut + maple purfling; side dots maple → replaced with **Luminlay**. Scarf headstock; truss + CF slots; taper via safety planer on drill press; ebony head veneer with B/W underlayers; volute-curved back veneer; template route outline; tuner holes; carve headstock; tenon with Irvin jig.

### 7.2 Geometry fit & bolt-on block

## 10. School contrast snapshot (Somogyi film vs Gore packs)

| Topic | This workflow | Gore packs |
|-------|---------------|------------|
| Top thickness | Stiffness method (Y03) | Modal \(f\) + mobility \(Y\) |
| Voicing | Tap after top on rim (Y13) | Closed-box FRF + mid-scale + mobility |
| Sides | Double + solid linings for stiffness | Often solid single; side mass; avoid over-rigid if tuning air |
| Brace into lining | Transverse full height; back braces notched in | Caution on tucking X for responsiveness |
| Lattice | Used with X hybrid | Often “vanilla” upper spectrum if lattice-dominant |
| Metrics | Almost none spoken | Explicit Hz / \(Y\) / 50¢ |
