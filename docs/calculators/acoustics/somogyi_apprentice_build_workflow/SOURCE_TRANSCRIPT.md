# Source transcript (working copy) — Somogyi apprentice first build

**ASR:** Samaji → Somogyi; Irvin; perforling → purfling; tide bond → Titebond; junior → tuner; velute → volute; lumenlay → Luminlay; parasys N/A.

Apprentice at Somogyi workshop, mid 2-year apprenticeship; first completed personal build. Did not follow Irvin’s process exactly; insight into workflow/setup.

**Top:** Plane edges → join → index holes → mark outline/soundhole/rosette. Square template + knife/scraper for rosette channels; ebony strips; rotate template. Sand top to **desired stiffness (Irvin’s methods)** → bandsaw rough-out.

**Bracing:** Brace bottoms to dome. Finger braces → X (notch/join/radius/glue) → laminated rosewood bridge plate (2-ply) fit to X → soundhole donut to X+transverse → glue plate+donut+transverse together → lattice (Irvin notch jig), radius, arms over plate, glue → extra plate piece + center-seam reinforcer → **cut soundhole**.

**Back:** Join, index, thickness, center strip, braces to dome, inter-brace strips, ends for lining notches, carve. Wood label; mask; shellac seal.

**Sides/rim:** Irvin **double sides** for stiffness — bend, laminate. L head block butts transverse; angle for back dome; curve for sides. End + cutaway blocks. Mold; glue blocks; sand rim to dome. **Solid linings** (choice, stiffer rim): 3-layer mahogany, cut to domes.

**Close/voice:** Fit top (head block to transverse; transverse into lining **full height**); glue; flush. **Voice:** carve braces to good tap response. Transverse reinforcer; Irvin signs (mirror riddle). Glue back; bindings (cradle router; cutaway compound curves; Irvin jigs); squares end graft.

**Neck:** Sideways mortise jig; fretboard slot jig + binding; 12th block inlay; Luminlay side dots; scarf; truss+CF; taper; veneers; bolt-on with 3-layer cross-grain block, wax body pocket; carve; frets.

**Finish/setup:** Bridge indexed via pin holes; epoxy pore fill; shellac; oil neck; hot-glue bridge; setup; demo recording.
