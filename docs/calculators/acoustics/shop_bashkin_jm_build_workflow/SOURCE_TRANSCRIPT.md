# Source transcript (working copy) — Bashkin JM build (**shop workflow**)

**Lane:** Shop / building — full acoustic process  
**Presenter:** Michael Bashkin, Fort Collins, CO (>25 years)  
**Build:** JM model (OM clarity/balance + larger-body low end)  
**ASR / cleanup:** stac → **StewMac?** (supplier); palero/pal faroh → **pau ferro**; bivan → **Bolivian**; curing/cured → **kerfed**; anglan/Angelman → **Engelmann**; Sito/adarac → **Sitka / Adirondack**; cortison/Quon → **quartersawn**; gobar/goar → **go-bar**; high glue → **hide glue**; engraft → **end graft**; perum boo → **perambuco?** (fingerboard dots); butal cellu solve → **butyl cellosolve**; 80,000 → **0.080"**; 50 thous → **0.050"**; 2–5,000 → **0.002–0.005"**; flitch match kept.

---

## Wood (~0:46–2:52)

Italian spruce top + very old pau ferro B&S (flitch-matched boards from ~1970s woodworker). Pau ferro ≈ rosewood tone camp (dense tropical; warmth/complexity). Spruce: light, stiff, stable; Italian preferred for this model. Sources: dealers + self-processed lumber.

## Join plates (~2:53–5:52)

Sand top/back ~**0.145"** working thickness. Inspect pitch pockets/anomalies; choose book-match orientation. Power jointer → jointer plane (wood moved across plane) → candle light-tight joint. **Hide glue** (epoxy for oily woods e.g. cocobolo). Side wedges + go-bar deck. Centerline; index holes.

## Back stripe / template / scrape (~5:58–7:55)

Optional back stripe (veneers + Bolivian RW); epoxy in go-bar; plane flush. JM template on index holes. Scrape 120-grit belt surface toward ~320-equivalent.

## Rosette (~8:00–14:12)

Shellac wipe; CNC inner/outer purfling rings (shop-made veneers); water-based glue. Excavate center; box-elder burl + pau ferro compass-point design; sand-shade; dry-fit CA wick with purflings as discoloration barrier. Soundhole + Bolivian RW inner ring.

## Sides / blocks / linings (~14:21–21:15)

Pau ferro sides ~**0.080"**; scrape; bend with light moisture + silicone blankets ~**270–320°F**; cool in mold (lignin reset). Neck block mahogany (PVA/Titebond); tail block Baltic birch ply. **Solid laminated** mahogany linings (3 bent plies in mold) — prefers vs kerfed; more glue area + long-term stiffness. Back linings cut to back arch/taper; top nearly flat. Many small clamps; radius-disc sand rim to dome.

## Bracing (~21:24–34:48)

Self-harvested **Engelmann** for top braces (low density / fingerstyle match); denser Sitka/Adi for back and soundhole support. QS split; density by H×L×W + weight. Router template for brace bottom radii (top vs back). X-notch jig with adjustable open/close. Hide glue ice-cube method; glue X arms sequentially; rough **A-profile** with angled laminate trimmer; then bridge plate, tone bars, fingers. Braces = structure + stress/vibration distribution; underbrace risk “too much information.” Back graft QS spruce stitch; let braces into linings; five mahogany side braces/side (stiffness + crack stop).

## Close box + voice (~35:24–43:52)

Glue-squeeze channel at neck block; glue back in mold. **Open-box back voicing:** tap FRF; start braces high, shave to lower frequency. Interior thin shellac (color + slow humidity exchange); sign label. Final brace sculpt; soundhole shellac barrier; truss-rod clearance notch; glue top with **Titebond** (hide too time-tight). Flush-route overhang; sand sides flat (binding reference). **Closed-box FRF** baseline; magnetic thickness gauge; may thin top perimeter **~0.002–0.005"**; re-measure.

## Binding / neck / set (~43:59–1:12:00)

Shop-made IRW bindings + purflings; sanding sealer; end graft; miters. Neck: CNC Honduran mahogany, dual-action truss rod, CF rods (epoxy), rosewood tenon splines; headstock overlay from same pau ferro + burl (no name on headstock — design signature). FB CNC compound radius; pernambuco? side+face dots. Neck set: placeholder frets/bridge; pitch/yaw via sandpaper flossing; ~**/32"** gap straightedge to bridge front (his settle knowledge); bolt-on serviceable joint.

## Finish / hardware / setup (~1:12:18–1:45:00)

Final sand 220; mineral spirits inspect. Mask glue surfaces. Neck: sealer + dark paste pore fill (mahogany). Body: clear **two-part epoxy** pore fill (protect maple purfling; IRW binding pores); top raw until thin wiped sealer. Nitro lacquer: ~4 coats day 1, double edges; sand flat (thin finish goal, ~20% solids); cure weeks; wet sand 1200→5000; buff. Permanent neck attach (Loctite on bolts; Titebond FB extension). Level FB; gold medium frets (CA spots); Waverly tuners; Brazilian RW bridge on **hide glue** (~**180 lb** string pull spoken); bone nut/saddle; string up; evaluate under tension; finish frets/setup. Young guitar will open with time; keep student mindset.
