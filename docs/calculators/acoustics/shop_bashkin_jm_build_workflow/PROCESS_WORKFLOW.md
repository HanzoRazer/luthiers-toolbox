# Bashkin JM — extracted process workflow

**Source pack:** this folder · **Lane:** shop / building  
**Builder:** Michael Bashkin · **Model:** JM (OM clarity/balance + larger-body low end)  
**Point IDs:** see [`ANNOTATED_WORKFLOW_NOTES.md`](./ANNOTATED_WORKFLOW_NOTES.md)  
**Rule:** Shop dialect. Thicknesses / temps / gaps are *his* numbers — not Toolbox defaults.

---

## Spine

```text
0  Intent & wood
1  Join top & back plates
2  Back stripe · template · scrape
3  Rosette · soundhole
4  Bend sides · blocks · solid linings · radius rim
5  Brace top & back · side braces
6  Glue back · open-box back voicing
7  Seal / label · glue top · flatten sides
8  Closed-box voicing (FRF + thickness)
9  Binding & purfling
10 Neck · fingerboard · hardware
11 Neck set (pitch / yaw)
12 Final sand
13 Pore fill · sealer · thin nitro · cure · rub out
14 Frets · tuners · bridge · nut/saddle
15 String up · setup · listen
```

---

## Stage 0 — Intent & wood

| Step | Action |
|------|--------|
| 0.1 | Choose body intent (here: JM between OM and large dread) |
| 0.2 | Select top (Italian spruce: light / stiff / stable) |
| 0.3 | Select B&S (pau ferro flitch-match when possible) |
| 0.4 | Source: dealers and/or self-processed boards |

**Gate:** Species + visual match locked before machining.

---

## Stage 1 — Join top & back plates

| Step | Action |
|------|--------|
| 1.1 | Wide-belt sand plates to working thickness (~0.145") |
| 1.2 | Inspect top for pitch pockets / anomalies |
| 1.3 | Choose book-match orientation; mark joint |
| 1.4 | Power jointer → jointer plane (wood across plane) |
| 1.5 | Candle for light-tight joint |
| 1.6 | Glue with hot hide glue (epoxy if oily wood) |
| 1.7 | Clamp: side wedges + go-bar down-pressure |
| 1.8 | Repeat for back; sand joints clean; mark centerline; drill index holes |

**Gate:** Light-tight center joints; centerline + indexes established.

---

## Stage 2 — Back stripe · template · scrape

| Step | Action |
|------|--------|
| 2.1 | (Optional) Route/inlay back stripe; epoxy; go-bar; plane flush |
| 2.2 | Mount body template on index holes; cut oversize safe |
| 2.3 | Scrape belt scratches (~120 grit → ~320-feel) |

---

## Stage 3 — Rosette · soundhole

| Step | Action |
|------|--------|
| 3.1 | Wipe shellac on top (protect spruce) |
| 3.2 | CNC cut inner/outer purfling channels; glue shop purfling (water-based) |
| 3.3 | Excavate center; install decorative mosaic (dry-fit → thin CA wick) |
| 3.4 | Cut soundhole; install inner ring (e.g. Bolivian rosewood) |

**Gate:** Rosette level; soundhole edged.

---

## Stage 4 — Rim (sides · blocks · linings)

| Step | Action |
|------|--------|
| 4.1 | Sand sides ~0.080"; mark outside face; template/cut; scrape |
| 4.2 | Light moisture; silicone heat blankets ~270–320°F; bend; cool in mold (~1–1.5 h) |
| 4.3 | Glue neck block (mahogany, PVA/Titebond) |
| 4.4 | Glue tail block (Baltic birch ply) |
| 4.5 | Make **solid laminated** linings (3 mahogany plies bent + glued in mold) — not kerfed |
| 4.6 | Shape back linings to back arch/taper; top linings nearly flat |
| 4.7 | Glue linings with many small clamps |
| 4.8 | Radius-disc sand rim flush to dome |

**Gate:** Rigid rim in mold; linings level to chosen radii.

---

## Stage 5 — Bracing

| Step | Action |
|------|--------|
| 5.1 | Split/rip QS brace stock (Engelmann for top; denser Sitka/Adi for back & soundhole) |
| 5.2 | Density-screen blanks (H×L×W + weight) |
| 5.3 | Router-profile brace bottoms to top/back radii |
| 5.4 | Cut X notch (jig sets X open/close) |
| 5.5 | Layout with bracing template |
| 5.6 | Hide glue: X arms sequential → rough A-profile → bridge plate, tone bars, finger braces |
| 5.7 | Stiffer spruce soundhole braces |
| 5.8 | Back: graft stitch → back braces → let brace feet into linings |
| 5.9 | Same let-in for top braces into top linings |
| 5.10 | Install side braces (here: five/side, mahogany) |

**Gate:** Pattern glued; feet let into linings; side braces in.

---

## Stage 6 — Glue back · open-box back voicing

| Step | Action |
|------|--------|
| 6.1 | Cut glue-catch channel at neck block (unreachable squeeze-out) |
| 6.2 | Glue back to rim in mold (rim already rigid) |
| 6.3 | Remove from mold when ready |
| 6.4 | **Voice back:** tap / frequency response; start braces high; shave height to lower frequency |

**Gate:** Back on target tap/FRF band (maker-specific; not published as Hz here).

---

## Stage 7 — Close top

| Step | Action |
|------|--------|
| 7.1 | Thin shellac inside (color + slow humidity exchange) |
| 7.2 | Sign/number label on back |
| 7.3 | Bandsaw top to outline; final brace-end sculpt/sand |
| 7.4 | Sign/date top; shellac soundhole barrier |
| 7.5 | Notch upper braces for truss-rod wrench clearance |
| 7.6 | Glue top with Titebond in mold (hide too time-tight for his method) |
| 7.7 | Flush-route overhang; sand sides flat (binding reference + side thickness) |

**Gate:** Closed box; sides flat and fair.

---

## Stage 8 — Closed-box voicing

| Step | Action |
|------|--------|
| 8.1 | Take closed-box frequency-response curve (baseline modes) |
| 8.2 | Map top thickness with magnetic gauge (closed box) |
| 8.3 | Stay above longevity thickness floor |
| 8.4 | If needed: thin top perimeter ~0.002–0.005"; re-measure FRF/thickness |

**Gate:** Modes + thickness window acceptable before binding.

---

## Stage 9 — Binding & purfling

| Step | Action |
|------|--------|
| 9.1 | Light sanding sealer (keep spruce clean; easier glue cleanup) |
| 9.2 | Process shop-made bindings/purflings |
| 9.3 | Route channels + end graft |
| 9.4 | Install top then back (miters); scrape/sand flush |

**Gate:** Bindings fair; plates clean for finish.

---

## Stage 10 — Neck · fingerboard · hardware prep

| Step | Action |
|------|--------|
| 10.1 | CNC rough neck (mahogany); truss channel; CF channels; tenon |
| 10.2 | Face-grain rosewood tenon splines; true headstock face; thin back; shape volute |
| 10.3 | Epoxy neck bolt hardware into tenon |
| 10.4 | Headstock overlay (same B&S wood + accents); back overlay |
| 10.5 | CNC fingerboard (compound radius, slots, markers) |
| 10.6 | Install dual-action truss rod |
| 10.7 | Epoxy CF rods; epoxy fingerboard (non-water glue) |

---

## Stage 11 — Neck set

| Step | Action |
|------|--------|
| 11.1 | Cut mortise + truss access in neck block |
| 11.2 | Placeholder frets + placeholder bridge |
| 11.3 | Set pitch & yaw (sandpaper flossing heel cheeks) |
| 11.4 | Check: straightedge on frets → ~1/32" gap at bridge front (his settle rule) |
| 11.5 | Trial bolt-on; mark FB/rosette intersection; fit heel cap & FB facets |

**Gate:** Pitch/yaw locked before finish (final glue-on after finish).

---

## Stage 12 — Final sand

| Step | Action |
|------|--------|
| 12.1 | Sand to 220; mineral spirits + bright light inspect |
| 12.2 | Hand-sand critical flats (upper bout under FB, neck joint faces) |

**Gate:** No scratches/tool marks before finish.

---

## Stage 13 — Finish

| Step | Action |
|------|--------|
| 13.1 | Mask nut, FB, neck joint, bridge patch, FB footprint |
| 13.2 | Neck: sealer → dark paste pore fill (mahogany; 1–2 coats) |
| 13.3 | Body B&S: clear 2-part epoxy pore fill (protect maple purfling; fill IRW binding pores) |
| 13.4 | Top: no pore fill; thin wiped sealer only |
| 13.5 | Soundhole plug; wipe sealer whole body |
| 13.6 | Nitro: ~4 coats day 1 (double edges); sand flat thin; build top coats |
| 13.7 | Cure weeks (longer better); wet sand ~1200→5000; buff |

**Gate:** Thin, flat, fully cured gloss.

---

## Stage 14 — Assembly hardware

| Step | Action |
|------|--------|
| 14.1 | Final neck attach (removable Loctite on bolts; Titebond FB extension) |
| 14.2 | Beam-sand FB flat on compound radius; open fret slots slightly |
| 14.3 | Install frets (medium gold wire; CA at ends/middle; hammer + clamp) |
| 14.4 | Upper frets after tension check with bridge on |
| 14.5 | Install tuners (e.g. Waverly) |
| 14.6 | Hide-glue bridge (cauls, indexing pins, heat; clamp overnight; ~180 lb joint load) |
| 14.7 | Ream pin holes; rough bone saddle & nut |

---

## Stage 15 — String · setup · listen

| Step | Action |
|------|--------|
| 15.1 | First string-up under full tension |
| 15.2 | Evaluate board with notched straightedge; finish upper frets if held |
| 15.3 | Dial truss, nut, saddle, intonation, fret polish |
| 15.4 | Listen for response/power/complexity; expect opening over days–months |

**Done:** Playable JM; iterate next guitar (student mindset).

## Glue matrix (quick ref)

| Joint | Glue |
|-------|------|
| Top/back center joints; braces; bridge | Hot hide glue |
| Oily woods (e.g. cocobolo) | Epoxy |
| Neck/tail blocks; top-to-rim; FB extension | PVA / Titebond |
| Rosette purfling rings | Water-based |
| Rosette mosaic | Thin CA (after water-based ring barrier) |
| CF rods; FB to neck; tuner bushings (as used) | Epoxy |
| Back stripe | Epoxy |

---

## Acoustic decision gates (only)

1. **Brace stock density** before cutting braces  
2. **Open-box back** tap/FRF → shave braces down (not up)  
3. **Closed-box FRF** + **thickness map** → optional perimeter thin  
4. **First string-up** listen / setup under tension  

Physics meters live in the physics lane; this pack records *when* he measures, not universal target Hz.
