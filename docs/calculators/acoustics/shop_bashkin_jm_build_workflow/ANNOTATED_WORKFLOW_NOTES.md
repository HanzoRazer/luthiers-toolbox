## Stage map (spine)

```text
Wood select
  → Join top/back plates (hide glue)
  → Back stripe / templates / scrape
  → Rosette + soundhole
  → Bend sides → blocks → solid linings → radius rim
  → Brace top & back (density-screened QS spruce) → side braces
  → Glue back → open-box back FRF voice
  → Seal/label → glue top → flatten sides
  → Closed-box FRF + thickness gauge → perimeter thin if needed
  → Bind/purfle → neck/FB/hardware → neck set
  → Final sand → pore fill → thin nitro → cure → rub out
  → Frets / tuners / bridge / nut-saddle → string → setup
```
