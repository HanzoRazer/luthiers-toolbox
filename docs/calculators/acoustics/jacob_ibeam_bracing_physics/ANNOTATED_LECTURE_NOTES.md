## Physics workflow remnant

```text
Prefer height for stiffness (cube-family)
  → Remove mid-depth mass (I-beam / holes / cores)
  → Keep glue flange + height where bridge loads
  → Pattern (X vs fan) from tension family
  → Optional: scallops/gaps for modal motion after structure OK
```
