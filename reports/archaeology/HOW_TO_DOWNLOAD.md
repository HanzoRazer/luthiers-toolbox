# How to get these files onto your PC

Do not copy-paste. The inventory is about 13 MB of text. Use the zip.

This folder is a **point-in-time Stage 1 scan** of `luthiers-toolbox` build
history (2026-01-01 → 2026-04-01 exclusive). It is not the IBG/AGE forensic
report ([PR #332](https://github.com/HanzoRazer/luthiers-toolbox/pull/332)).

## Download

**Use this link once the PR is merged** — it follows `main` and survives branch deletion:

https://github.com/HanzoRazer/luthiers-toolbox/raw/main/reports/archaeology/vec_archaeo_001.zip

**Before the PR is merged**, that link 404s because the file is not on `main` yet. Use the
branch link instead:

https://github.com/HanzoRazer/luthiers-toolbox/raw/cursor/vec-archaeo-001-inventory-5bd1/reports/archaeology/vec_archaeo_001.zip

> **The branch link is temporary.** It stops working as soon as
> `cursor/vec-archaeo-001-inventory-5bd1` is deleted, which normally happens on merge.

Then in Downloads: right-click the zip → **Extract All**.

Inside you will have `TIMELINE.md` (the report), `SCHEMA.md` (field names and types for
Stage 2), plus `commits.jsonl`, `files.jsonl`, `sessions.json`, and `raw/`.

## If the link opens in the browser instead of downloading

1. Open the file page — after merge:
   https://github.com/HanzoRazer/luthiers-toolbox/blob/main/reports/archaeology/vec_archaeo_001.zip
2. Click the **Download raw file** button (down-arrow icon, top right of the file view).
3. Extract the zip as above.
